# Text Autocomplete

Проект по автодополнению текстов на основе датасета коротких постов (Sentiment140).
Реализованы и сравнены две модели: обученная с нуля LSTM и предобученный трансформер distilgpt2.

## Данные

Датасет: [Sentiment140] — 1.6М коротких твитов на английском языке.

После очистки (lowercase, удаление ссылок и спецсимволов, фильтрация по длине ≥ 7 слов): **~1.27М твитов**.

Разбивка: 80% / 10% / 10% (train / val / test).

## Модели

### LSTM
- Однонаправленная LSTM, обучена с нуля на тренировочных данных
- `embed_dim=64`, `hidden_dim=128`, `num_layers=2`
- Токенизация: собственный словарь (~45К слов, `min_freq=10`)
- Обучение: 10 эпох, `AdamW`, `lr=3e-3`, `CrossEntropyLoss`

### distilgpt2
- Предобученная модель из HuggingFace Transformers
- Используется без дообучения через `pipeline("text-generation")`
- Жадная генерация (`do_sample=False`)

## Результаты

| Модель     | ROUGE-1 | ROUGE-2 |
|------------|---------|---------|
| LSTM (val) | 0.0641  | 0.0070  |
| distilgpt2 (val) | 0.0381 | 0.0029 |
| **LSTM (test)** | **0.0642** | **0.0084** |

## Выводы

LSTM, обученная с нуля на твитах, показала результат выше чем distilgpt2 по обеим метрикам.

Причины:
- distilgpt2 обучен на книгах и веб-текстах — его распределение слов сильно отличается от разговорного языка твитов
- LSTM обучена именно на этом домене и знает характерные паттерны коротких постов
- Метрики обеих моделей невысокие — твиты непредсказуемы по природе, одному префиксу соответствует огромное число возможных продолжений

**Рекомендация разработчикам:** для мобильного приложения использовать LSTM — она легче, быстрее, лучше подходит под домен и не требует загрузки весов предобученной модели. При наличии ресурсов стоит дообучить distilgpt2 на твитах — это потенциально даст лучший результат, но увеличит размер модели.
